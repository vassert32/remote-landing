# remote-landing

Лендинг персонального менторства: вывод IT-специалистов с опытом на удалённый оффер с оплатой в валюте.

## Стек

| | |
|---|---|
| Каркас | Astro 5, статическая сборка, TypeScript |
| Анимации | GSAP 3 + ScrollTrigger |
| Скролл | Lenis |
| Стили | нативный CSS с токенами, scoped по компонентам. Без UI-фреймворка |
| Иконки | astro-icon, наборы Phosphor и Simple Icons |
| Шрифты | Onest и JetBrains Mono, самохостинг, подмножества latin / latin-ext / cyrillic |

## Команды

```bash
npm install
```

```bash
npm run dev
```

| Команда | Что делает |
|---|---|
| `npm run dev` | локальный сервер на `localhost:4321` |
| `npm run build` | статическая сборка в `dist/` |
| `npm run preview` | просмотр собранного результата |
| `npm run check` | проверка типов и разметки Astro |
| `npm run fonts:sync` | копирует подмножества шрифтов из `node_modules` в `public/fonts` |
| `npm run photos` | пересобирает `src/assets/mentor.jpg` из исходника в `assets-source/` |
| `npm run og` | пересобирает превью для соцсетей `public/og.jpg` |

`fonts:sync`, `photos` и `og` запускаются вручную: их результат закоммичен, в CI они не нужны.

## Структура

```
src/
  data/content.ts        все тексты и данные страницы
  layouts/Base.astro     head, мета, шрифты, JSON-LD
  components/            секции страницы
  styles/
    tokens.css           дизайн-токены
    fonts.css            @font-face
    base.css             сброс, сетка, типографика, примитивы документа
  scripts/motion.ts      Lenis + ScrollTrigger
tools/                   служебные скрипты сборки ассетов
```

Правки текста почти всегда делаются в `src/data/content.ts`, вёрстку трогать не нужно.

## Дизайн-система

Направление: швейцарская редакторская сетка поверх метафоры официального документа.

**Цвет.** Один акцент на всю страницу, `--stamp` ультрамарин. Он означает подтверждение: печать в оффере, итоговая сумма в расчёте, активный этап программы, состояния фокуса и наведения. Больше ни один цвет на странице не появляется.

**Тема.** Только светлая. Метафора бумаги в тёмной теме не работает, поэтому `color-scheme: light` зафиксирован.

**Форма.** Радиус скруглений равен нулю везде. Границы и разделители всегда в один пиксель, кроме итоговых линий расчёта.

**Типографика.** Onest на заголовки и текст, JetBrains Mono на цифры, поля документов и микро-подписи. Все числовые колонки используют табличные цифры (`.num`), поэтому разряды выравниваются по вертикали.

**Контраст.** `--ink-mute` (4.82:1) это самый светлый цвет, допустимый для текста. `--ink-faint` не проходит AA и используется только для декора вроде линии зачёркивания.

**Движение.** Первый экран анимируется чистым CSS: он не должен зависеть от того, доехал ли JS-модуль. Всё остальное живёт ниже сгиба и управляется ScrollTrigger. Класс `.motion` ставит сам модуль анимаций, поэтому без JS страница остаётся полностью видимой и рабочей. При `prefers-reduced-motion: reduce` не запускается ничего, кроме линейки под шапкой.

## Деплой

Пуш в `main` запускает `.github/workflows/deploy.yml`: сборка на Node 22 и `rsync` папки `dist/` на VPS в `/var/www/remote-landing/`.

Нужны секреты репозитория: `VPS_HOST`, `VPS_USER`, `VPS_SSH_KEY`.

## Что осталось сделать

- В `astro.config.mjs` стоит временный домен в поле `site`. От него зависят canonical и `og:url`, заменить на боевой.
- Фотография ментора вырезана из скриншота галереи и ограничена по разрешению исходником 590x780. Нормальная съёмка заметно улучшит секцию.
- Цифры `USD 8 500` и `4 месяца` в карточке оффера это заявления заказчика. Скриншот оффера или отзывы учеников сильно усилили бы блок доверия.
